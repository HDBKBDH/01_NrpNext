## 五、成本分摊算法

### 5.1 采购成本分摊（Disassembly Note）

```python
def allocate_purchase_cost(note):
    """
    按采购时参考价权重分摊整机成本到零件
    """
    total_ref = sum(item.market_ref_price_cny for item in note.items)
    if total_ref == 0:
        raise ValueError("参考价总和不能为0")
    
    total_cost = note.purchase_receipt.cny_settlement_cost
    ratio = total_cost / total_ref
    
    for item in note.items:
        item.allocated_purchase_cost = item.market_ref_price_cny * ratio
```

### 5.2 物流成本分摊（Logistics Batch）

```python
def allocate_logistics_cost(batch):
    """
    按采购时参考价权重分摊批次成本到零件
    """
    total_ref = sum(item.market_ref_price_cny for item in batch.allocated)
    if total_ref == 0:
        return
    
    total_cost = batch.total_cost
    ratio = total_cost / total_ref
    
    for item in batch.allocated:
        item.allocated_cost = item.market_ref_price_cny * ratio
        # 更新到 Disassembly Note
        dn_item = get_dn_item(item.serial_number)
        dn_item.allocated_logistics_cost = item.allocated_cost
```

### 5.3 资金占用成本计算

```python
def calculate_capital_cost(item, as_of_date):
    """
    资金占用成本 = 库存成本 × 资金成本率 × 持有天数/365
    """
    capital_rate = frappe.db.get_single_value("Trade Settings", "capital_cost_rate") / 100
    holding_days = (as_of_date - item.purchase_date).days
    capital_cost = item.final_cost * capital_rate * (holding_days / 365)
    return capital_cost
```

## 七、6 个报表设计

### 7.1 单件毛利明细（Script Report）

```sql
SELECT 
    sn.name AS serial_number,
    i.item_name AS model,
    dn.final_cost AS cost,
    COALESCE(si.grand_total, 0) AS sale_amount,
    mph.market_price_cny AS current_price,
    (si.grand_total - dn.final_cost) AS profit,
    ((si.grand_total - dn.final_cost) / dn.final_cost * 100) AS profit_margin
FROM `tabSerial Number` sn
JOIN `tabDisassembly Note Item` dn_item ON dn_item.serial_number = sn.name
JOIN `tabDisassembly Note` dn ON dn.name = dn_item.parent
JOIN `tabItem` i ON i.name = dn_item.item
LEFT JOIN `tabMarket Price History` mph ON mph.model = dn_item.item 
    AND mph.price_date = (SELECT MAX(price_date) FROM `tabMarket Price History` WHERE model = dn_item.item)
LEFT JOIN `tabSales Invoice Item` sii ON sii.serial_no = sn.name 
    AND sii.parent = (SELECT name FROM `tabSales Invoice` WHERE docstatus=1)
WHERE dn.docstatus = 1
```

### 7.2 库存市值（Query Report）

```sql
SELECT 
    i.item_name AS model,
    w.warehouse_name AS warehouse,
    SUM(sn.qty) AS quantity,
    mph.market_price_cny AS unit_price,
    SUM(sn.qty) * mph.market_price_cny AS total_value
FROM `tabSerial Number` sn
JOIN `tabItem` i ON i.name = sn.item_code
JOIN `tabWarehouse` w ON w.name = sn.warehouse
LEFT JOIN `tabMarket Price History` mph ON mph.model = sn.item_code 
    AND mph.price_date = (SELECT MAX(price_date) FROM `tabMarket Price History` WHERE model = sn.item_code)
WHERE sn.qty > 0 AND w.is_virtual = 0
GROUP BY i.item_name, w.warehouse_name
```

### 7.4 涨价排行榜（Script Report）

```python
def get_price_change(days=30):
    """
    计算各型号 N 天涨跌幅
    """
    models = frappe.get_all("Market Price History", 
                           fields=["model"],
                           distinct=True)
    
    result = []
    for m in models:
        history = frappe.get_all("Market Price History",
                                filters={"model": m.model},
                                fields=["price_date", "market_price_cny"],
                                order_by="price_date asc")
        
        if len(history) < 2:
            continue
            
        current = history[-1]
        past = get_price_n_days_ago(history, days)
        
        if past:
            change_pct = (current.market_price_cny - past.market_price_cny) / past.market_price_cny * 100
            result.append({
                "model": m.model,
                "current_price": current.market_price_cny,
                "past_price": past.market_price_cny,
                "change_pct": change_pct
            })
    
    return sorted(result, key=lambda x: x["change_pct"], reverse=True)
```

### 7.6 资金占用（Script Report）

```python
def get_capital_occupation(as_of_date=None):
    """
    计算资金占用情况
    """
    if not as_of_date:
        as_of_date = frappe.utils.today()
    
    capital_rate = frappe.db.get_single_value("Trade Settings", "capital_cost_rate") / 100
    
    # 查询所有在库零件（可售 + 自用，不含虚拟仓）
    items = frappe.db.sql("""
        SELECT 
            sn.name,
            sn.item_code,
            sn.warehouse,
            dn_item.purchase_date,
            dn_item.final_cost
        FROM `tabSerial Number` sn
        JOIN `tabDisassembly Note Item` dn_item ON dn_item.serial_number = sn.name
        JOIN `tabWarehouse` w ON w.name = sn.warehouse
        WHERE sn.qty > 0 AND w.is_virtual = 0
    """, as_dict=True)
    
    result = []
    for item in items:
        holding_days = (getdate(as_of_date) - getdate(item.purchase_date)).days
        capital_cost = item.final_cost * capital_rate * (holding_days / 365)
        result.append({
            "serial_number": item.name,
            "item_code": item.item_code,
            "warehouse": item.warehouse,
            "final_cost": item.final_cost,
            "holding_days": holding_days,
            "capital_cost": capital_cost
        })
    
    return result
```

## 十、开发注意事项

1. **DocType JSON 格式** —— v16 使用 `fieldtype` 而非旧的 `fieldtype` 拼写差异，注意模板
2. **子表（Child Table）** —— 必须 `istable: 1`，且有 `istable: 1` 的 DocType 名为 `<Parent> Item` 或自定义
3. **命名系列** —— `naming_series` + `autoname: "naming_series:"` 
4. **单例（Single）** —— `issingle: 1`，通过 `frappe.get_single("Trade Settings")` 访问
5. **权限** —— 开发阶段用 Administrator 跑 patch，生产环境需要 System Manager 角色
6. **索引** —— `Serial Number` 上的 `serial_number`、`Market Price History` 上的 `(model, price_date)`
