## 二、数据持久化（bind mount）

**已从 Docker named volume 迁移到主机 bind mount：**

| 数据 | 路径 | 权限 |
|------|------|------|
| MariaDB | `/opt/erp/db-data/` | 999:999 |
| 站点配置 | `/opt/erp/sites/` | 1000:0 |

**生效的 compose 文件组合：**
```bash
cd /opt/erp/frappe_docker
docker compose \
  -f compose.yaml \
  -f overrides/compose.mariadb.yaml \
  -f overrides/compose.redis.yaml \
  -f overrides/compose.proxy.yaml \
  -f overrides/compose.bind-mount-db-data.yaml \
  -f overrides/compose.bind-mount-sites.yaml \
  <command>
```

⚠️ **重要**：`docker compose` 命令必须带全部 6 个 `-f` 参数，否则会退回 named volume，导致数据分叉。

## 三、备份

### 自动备份
- **时间**：每日 03:17
- **脚本**：`/usr/local/bin/frappe-backup.sh`
- **日志**：`/var/log/frappe-backup.log`
- **保留**：14 天（脚本自动清理）
- **bench 站点级保留**：14 天 / 3 个月 / 保留 3 份本地副本

### 手动备份
```bash
/usr/local/bin/frappe-backup.sh
```

### 备份位置
| 路径 | 内容 |
|------|------|
| `/opt/erp/backup/YYYYmmdd_HHMMSS/` | 带时间戳的完整备份 |
| `/opt/erp/backup/latest/` | 最新备份副本 |
| 容器内 `sites/erp.motitoo.com/private/backups/` | bench 原生备份 |

⚠️ **注意**：容器时间戳是 UTC，主机是 CST，相差 8 小时。脚本已自动处理。

### 恢复
```bash
# 1. 查看可用备份
ls -la /opt/erp/backup/

# 2. 恢复到站点
docker cp /opt/erp/backup/latest/<timestamp>-erp_motitoo_com-database.sql.gz frappe_docker-backend-1:/tmp/
docker cp /opt/erp/backup/latest/<timestamp>-erp_motitoo_com-files.tgz frappe_docker-backend-1:/tmp/
docker cp /opt/erp/backup/latest/<timestamp>-erp_motitoo_com-private-files.tgz frappe_docker-backend-1:/tmp/

docker exec frappe_docker-backend-1 sh -c "bench --site erp.motitoo.com restore /tmp/<timestamp>-erp_motitoo_com-site_config_backup.json \
  --with-public-files /tmp/<timestamp>-erp_motitoo_com-files.tgz \
  --with-private-files /tmp/<timestamp>-erp_motitoo_com-private-files.tgz \
  --force"
```

## 四、常用运维命令

```bash
# 进入 bench 环境
cd /opt/erp/frappe_docker

# 容器列表
docker ps --format 'table {{.Names}}\t{{.Status}}'

# bench 命令（在容器内执行）
docker exec -it frappe_docker-backend-1 bench --site erp.motitoo.com <command>

# 常用 bench 命令
docker exec frappe_docker-backend-1 bench --site erp.motitoo.com list-apps
docker exec frappe_docker-backend-1 bench --site erp.motitoo.com migrate
docker exec frappe_docker-backend-1 bench --site erp.motitoo.com build
docker exec frappe_docker-backend-1 bench --site erp.motitoo.com clear-cache
docker exec frappe_docker-backend-1 bench --site erp.motitoo.com backup --with-files

# 数据库直查
docker exec frappe_docker-db-1 mariadb -u _945e68dd4d82c4d9 -p<DB_PASSWORD> _945e68dd4d82c4d9

# 日志查看
docker logs frappe_docker-backend-1 --tail 100
docker logs frappe_docker-scheduler-1 --tail 100
docker logs frappe_docker-queue-short-1 --tail 100

# 队列状态
docker exec frappe_docker-backend-1 bench --site erp.motitoo.com doctor
```

## 五、常用 SSH

> ⚠️ **凭据安全**：本仓库不存放任何密码。
> SSH 已配置免密登录（`~/.ssh/id_mac_local`），数据库密码在服务器
> `/opt/erp/frappe_docker/.env`（权限 600）。
> 早期版本曾在开发过程中明文暴露过 root 与数据库凭据，建议轮换。

```bash
# 免密登录（推荐）
ssh root@110.42.60.173

# 指定密钥
ssh -i ~/.ssh/id_mac_local root@110.42.60.173
```
